# Triage labels

| Papel canônico | Label no tracker | Significado |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | Precisa de avaliação do mantenedor |
| `needs-info` | `needs-info` | Aguarda informações do autor |
| `ready-for-agent` | `ready-for-agent` | Está completamente especificado e pronto para um agente |
| `ready-for-human` | `ready-for-human` | Requer implementação humana |
| `wontfix` | `wontfix` | Não será executado |

Quando um skill mencionar um papel de triagem, use a label correspondente nesta tabela.
