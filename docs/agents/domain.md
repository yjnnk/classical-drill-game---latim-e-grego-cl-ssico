# Domain docs

Este repositório usa documentação de domínio em contexto único.

## Antes de explorar

Leia, quando existirem:

- `CONTEXT.md` na raiz;
- ADRs relevantes em `docs/adr/`.

Se esses arquivos ainda não existirem, prossiga silenciosamente. Eles devem ser criados somente quando decisões ou termos reais precisarem ser registrados.

## Vocabulário

Use nos issues, testes e código os termos definidos no glossário de `CONTEXT.md`. Evite sinônimos que o glossário tenha rejeitado.

Quando um conceito necessário não estiver no glossário, verifique se ele é realmente parte do domínio antes de propor sua inclusão.

## ADRs

Se uma mudança contradisser um ADR existente, sinalize o conflito explicitamente em vez de sobrescrever silenciosamente a decisão.
